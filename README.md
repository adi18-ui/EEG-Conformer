# EEG-Conformer Reproduction for Motor Imagery EEG Classification

This repository contains a reproduction of the paper:

**"EEG Conformer: Convolutional Transformer for EEG Decoding and Visualization"**  
Song et al., IEEE Transactions on Neural Systems and Rehabilitation Engineering, 2023.

The goal of this project was to reproduce the EEG-Conformer architecture and training pipeline on the **BCI Competition IV Dataset 2a** 

---

## Overview

EEG-Conformer combines:

- Temporal convolution for local temporal features
- Spatial convolution across EEG channels
- Multi-head self-attention for global temporal dependencies
- A fully connected classifier for motor-imagery classification

---

## Dataset

**BCI Competition IV Dataset 2a**

- 9 subjects
- 22 EEG channels
- Sampling frequency: 250 Hz
- 4 motor-imagery classes:
  - Left hand
  - Right hand
  - Both feet
  - Tongue

---

## Data Augmentation

The original paper uses **Segmentation and Reconstruction (S&R)** augmentation. In this, each EEG trial is divided into 8 segments. New synthetic trials are generated by selecting corresponding segments from different trials belonging to the same motor-imagery class. This increases training-data diversity.
